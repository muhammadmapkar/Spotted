# Spotted: Feature Roadmap

Spotted turns reels into real places, connecting creators, restaurants and their audience.

## Phase 1: Core (build first)
- [x] **One-tap "Spot it" tagging**: tag restaurant and dish in a reel; the post becomes a map pin
- [x] **Pin-to-reel map**: followers tap a pin to watch the reel; "near me" mode
- [x] **Creator profile page**: shareable link-in-bio with all spots, saves and city lists
- [x] **Proof dashboard**: saves, visits, "went because of you", bookings
- [x] **Collab inbox**: restaurants send briefs (dates, offer: free meal, fee or commission); creator accepts or declines in one tap
- [x] **Rewards**: pay per verified visit, referral codes, free-meal tier, with the price stated upfront
- [x] **Verified visits**: check-in or receipt confirmation to block fake spots

## Phase 2: Sharing and growth
- [x] "Spotted" badge / sticker for stories and reels
- [x] Shareable lists (e.g. "Best brunch in Bandra", "10 date-night spots")
- [x] Save-to-visit with nearby reminders
- [x] Streaks and levels: Newcomer, Local, Tastemaker
- [x] Group plans: send spots to friends and vote
- [x] Trending this week, by city and cuisine

## Phase 3: Restaurant tools
- [ ] Claimed restaurant profile: menu, hours, booking or order link
- [ ] "Creator wanted" board with budget and dates
- [ ] Campaign analytics: visits and covers per creator
- [ ] Launch offers (e.g. first 50 Spotted visitors get a free dessert)

## Later
- [ ] Reel-to-real search: paste a reel, find the place
- [ ] AI captions and tag suggestions from video
- [ ] Dietary filters (veg, halal, jain)
- [ ] Creator leaderboards and seasonal "Spotted Awards"
