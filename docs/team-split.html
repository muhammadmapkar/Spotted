Do this first

  1. Merge the branch. improvements-round-1 is 2 commits ahead of main. Open a pull request into main so everyone starts from the same code.
  2. Give everyone access. Invite the team to GitHub and Expo. Builds run on the owner's Expo account, so ask the owner before starting one.
  3. Check the account name. app.json says the owner is sarahnaziahmed-debug, but the GitHub account is sarahnazirahmed-debug. One may be a typo.
